AUTHORIZED TAILSCALE DEVICES

Remote Devices

Pair a device running the CloudOps agent. Connections are restricted to Tailscale IPv4 addresses.

File sharing requires recipient approval. Only a file you select is sent, and it remains in agent memory until the recipient approves or rejects it. Approve files only from devices you trust; received files are not scanned. Approved files are saved in CloudOps Shared/Received; existing files are never overwritten. There is no remote file browsing or direct editing.
Windows device setup
  1. Install Tailscale on both computers and sign in to the same private tailnet.
  2. Copy this project's files to the Windows PC. In PowerShell, open the project folder and install its dependencies: py -3 -m venv .venv then .\.venv\Scripts\python.exe -m pip install -r requirements.txt.
  3. Create the agent key with py -3 -c "import secrets; print(secrets.token_urlsafe(32))". Keep the generated key private.
  4. Generate a second, private approval key for this device with the same Python secrets command. Set both keys and bind only to this PC's Tailscale address:
$env:CLOUDOPS_AGENT_TOKEN = "PASTE_THE_GENERATED_KEY"
$env:CLOUDOPS_AGENT_APPROVAL_TOKEN = "PASTE_A_DIFFERENT_LOCAL_APPROVAL_KEY"
$env:CLOUDOPS_AGENT_BIND = (tailscale ip -4 | Select-Object -First 1).Trim()
.\.venv\Scripts\python.exe remote_agent.py

The approval key is used only by the CloudOps dashboard running on this same device; never enter it on another device. Start the dashboard in another PowerShell window with the same three environment variables and .\.venv\Scripts\python.exe app.py. For both-way sharing, run CloudOps and an agent on both devices, and pair each device from the other device's dashboard using that device's agent key. Allow inbound TCP 8765 only from the other device's Tailscale IP.
